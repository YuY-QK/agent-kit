
## Progress and context

- Each project keeps one short progress summary: `docs/progress.md`, unless the project's `AGENTS.md` names another file. It holds only the current status (what is done, with verification results), the plan (stages and checkpoints) and open items. Rules belong in their own documents, not here.
- Update it whenever a part of the work is finished (a stage or a batch), and keep it brief.
- A new session must be able to continue from the project's `AGENTS.md` and this summary alone, without scrolling back through old conversations. When a conversation gets long, update the summary and tell me it is time to start a new session.
